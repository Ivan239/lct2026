## Осталось — на человеке

1. **Видео до 7 минут**, запись экрана без склеек и ускорения на этапе генерации:
   загрузка шаблона, **которого нет в датасете** → бриф или контент-пакет →
   генерация (идёт 40–70 с) → превью → находки аудита и «Исправить выбранные» →
   скачивание .pptx/.pdf/.html → открыть .pptx в PowerPoint/Keynote и показать,
   что объекты редактируемые.
2. **Питч-презентация** на шаблоне ЛЦТ: проблема → подход → архитектура пайплайна →
   демо → архитектура аудита → выводы; слайды 7–11 шаблона не менять.
3. **Форма сдачи**: одно поле — одна ссылка (репозиторий; в README есть ссылки на
   релиз с колодами, документы и видео).
4. **Тег финальной версии** после последнего коммита (`git tag v1.0 && git push --tags`) —
   до 23:59.

## Известные ограничения (честно в README)

- Нативные графики и таблицы не собираются: слайды шаблона вокруг чужой диаграммы
  или таблицы исключены из подбора.
- Изображения не генерируются (задача со звёздочкой для топ-10): на месте картинки —
  рамка-скелет с описанием сюжета.
- Шрифтов шаблона нет на Linux-сервере — в превью/.pdf/.html подставляется
  Liberation Sans, и сервис это называет; в .pptx шрифты оригинальные.
- Шаблоны датасета в git не лежат (материалы организаторов): после клонирования их
  нужно загрузить через интерфейс.

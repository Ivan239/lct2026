## Что сделано (нечётная — топ-1 дефект)

Топ-1 — один некорректный блок роняет весь прогон: четыре прогона потеряны
целиком. Причина одна: план кладёт на слайд «одна большая цифра» `count=1`,
модель отдаёт три-четыре пункта/пары, `_validate_block` пять раз подряд
отвергает ответ, `ValueError` доходит до `generate_deck`.

1. **Излишек режется, а не отвергается** (`_take_exactly`): первые N
   корректных элементов — модель ставит важное первым. Недостача — по-прежнему
   повтор: недостающее код не выдумает. Для stats сначала отсеиваются
   битые пары, потом берутся первые N.
2. **Деградация вместо падения:** если блок так и не собран после всех
   повторов, слайд пропускается с причиной в `skipped`, дека собирается из
   остальных — в цикле (`generate_deck`) и в API (`_plan_two_phase`, где
   раньше весь двухфазный путь откатывался на легаси). Ловятся только
   ошибки содержания (`ValueError`/`KeyError`); сетевые — наверх, цикл
   пишет их как «пропущено по сети».

**До/после на одной деке:** до — исключение, деки нет; после — 10 слайдов,
0 пропущенных (обрезки хватило, деградация не понадобилась).

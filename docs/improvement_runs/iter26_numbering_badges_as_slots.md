# Итерация №26 — буллеты попадали в номерные бейджи шириной 0.26″

## Генерация: пропущена по сети (десятый раз подряд)

OAuth недоступен. Деки нет, оценку 10.1 и взвешенный итог не выставлял.

## Где искал

Кросс-шаблонный смоук покрывал только путь СИНТЕЗА. Нативное заполнение слайдов
шаблона — то, из чего в реальных деках состоит большинство слайдов — не было
покрыто вообще. Прогнал по нему состязательный контент на всех шаблонах.

## Две ложные тревоги, которые я снял сам

Первый замер показал «контент потерян на 1 из 4 слайдов» и «9 разрывов слов».
Оба — артефакты моего же пробника:

- текст был на месте, но с МЯГКИМИ ПЕРЕНОСАМИ (`\xad`), и поиск подстроки их не
  учитывал (`soft_hyphenate_long_words` — штатное поведение для узких боксов);
- «разрывы» считались по словам целиком, хотя по мягкому переносу рендерер вправе
  перенести законно.

После поправки: потерь контента нет нигде, разрывов нет на трёх шаблонах из
четырёх. Осталось 3 настоящих на Т—Ж Универсальном.

## Настоящий дефект

На слайде 2 Т—Ж Универсального пункты попадали в боксы шириной **0.26 дюйма**
(19pt полезной ширины) и ужимались до 8pt. Рендер: три микроскопических столбика
из обрубков «Клиентоо-/риенти-/рова-/нность», при этом весь слайд пустой.

Причина: `_find_slot_boxes` ищет сетку одинаковых боксов, и ряд номерных бейджей
«01»…«06» проходит все геометрические тесты идеально — минимума ширины не было.

**Порог не угадан, а измерен по корпусу:**

```
Т—Ж Учебный        слот-сетки 2.86in (29%), 3.11in (31%)
Т—Ж Моно           1.93in (19%)
Т—Ж Универсальный  1.85in (18%)   и   0.26in (3%)  ← бейджи
```

Между 3% и 18% — большой разрыв, порог поставлен на 10% ширины слайда.

## Проверка

- Сетка бейджей больше не выбирается; на том же слайде находится ПРАВИЛЬНАЯ сетка
  1.56in (боксы «Название пункта»). Легитимные сетки других шаблонов не тронуты.
- Рендер посмотрел глазами: три пункта стоят читаемыми строками вместо 8pt-обрубков.
- Тесты: **130 passed** (+1 регрессионный на этот случай).

## Очередь

1. **[генерация] Размеры в соседних слотах разъезжаются** — на исправленном
   рендере «Взаимодействие» заметно крупнее соседей: каждый слот подбирает
   размер сам. Нужна гармонизация по строке слотов (аналог
   `harmonize_clone_font_sizes`, но внутри слайда).
2. **[генерация] Полупустые слайды** — упирается в Пункт 11 (не трогаем).
3. **[генерация] Слоты без ответа** («КОММЕНТАРИЙ», «Название пункта»).

# Фича: скелеты изображений (по запросу пользователя)

Картинки пока НЕ генерируются — вместо них деки получают СКЕЛЕТ: пунктирная рамка с
подписью внутри, что должно быть на изображении. Только для композиции; при оценке
учитывается РАСПОЛОЖЕНИЕ изображений.

## Генерация

- Новая роль/архетип `image_caption` (в `OUTLINE_ROLES`, `SYNTHESIZABLE_TYPES`).
  Аутлайн просит добавить 1 такой слайд, где визуал усиливает (обзор/процесс/результат).
- `generator/synthesizer.py::synthesize_image_caption` + `_add_image_placeholder`:
  рисует скруглённую рамку с ПУНКТИРНОЙ обводкой (accent), без заливки, с подписью
  «ИЗОБРАЖЕНИЕ / <что изобразить>» по центру. Шейп именуется `img_placeholder`.
- Блок `image_caption` = `{title, image:"<что изобразить, 3-8 слов>"}` (валидируется).
- Клиренс под заголовком: резервируется ≥2 строки (рамка большая — любой нахлёст на
  2-строчный заголовок бросается в глаза; поймал глазами и починил — рамка теперь
  чисто под заголовком).

## Оценка (учитывает расположение изображений)

- `deterministic.deck_media` считает `placeholders`.
- `evaluate.py`: при наличии скелетов (и без реальных картинок) критерии РАЗМЕЩЕНИЯ
  4.1/4.3/4.4/4.5 применимы (оцениваются), а КАЧЕСТВО 4.2 и стиль `dop_image_style` —
  N/A (реальной картинки ещё нет). Раздел «Изображения» перестал быть полностью N/A.
- `judge.py`: vision-судье в промпт добавляется контекст «это скелеты-заглушки, оцени
  расположение/размер/уместность, не качество».

## Проверено

- Рендер + ГЛАЗА: слайд-скелет — пунктирная рамка с подписью, читается, по центру;
  на 2-строчном заголовке нахлёста НЕТ (после фикса клиренса).
- Оценка живьём: images-бакет применим (5.0), 4.1/4.3/4.4 оценены, 4.2 = N/A.
- Тесты: **105 passed** (unit: `deck_media` считает скелеты; меню-тест обновлён —
  `image_caption` теперь предлагаемая роль).

## Примечание

Замечен пре-существующий предел iter4-фикса: когда генерация форсит РОВНО GigaChat-2-Max
(`--model GigaChat-2-Max`), у неё нет фолбэка (сеть безопасности = Max), и серия битого
JSON от самой Max роняет прогон. Не связано с этой фичей; кандидат в очередь — дать Max
фолбэк на второй тир или ретраить прогон целиком.

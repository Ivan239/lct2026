# Итерация №80 — показатель считался заголовком слайда

## Генерация: пропущена по сети (шестьдесят пятый раз подряд), за секунды

Деки от живой модели нет, оценка 10.1 не выставлялась.

## Пункт очереди: висячие строки у Учебного на `wordy`

Прошёл по флагу `dop_orphans` 3 из 5 и нашёл не висячую строку, а подмену:

```
харнесс считает заголовком: '-40%'   (72pt, T=3.21)
настоящий титул:            'Результаты пилотного внедрения…' (18pt, T=1.22) → в контент
```

Титул, попав в «контент», объявлялся висячей строкой. И хуже: критерий 2.1
(«длинные заголовки») этого слайда НЕ ВИДЕЛ вовсе — считал 2 длинных заголовка
там, где их 3.

Причина — взаимодействие двух моих же правок: `_pick_title_shape` штрафует
шейпы ниже верхней четверти ×0.5, а iter70 дала показателю кегль шаблона (72pt).
Половина от 72 всё ещё больше 18.

## Правка и отвергнутая первая версия

Первый признак — «короткий текст, в котором есть цифра» — я замерил по корпусу
и **отбросил**: под него попадает «Top 7», настоящий заголовок реального
шаблона. Признак уточнён до «половина непробельных символов — цифры и знаки»:

```
'-40%' '+18' 'x3' '20 227 000'  → ПОКАЗАТЕЛЬ
'Top 7' (25%)  '4 дня' (25%)  'Итоги 2025 года' → текст
```

Показатель получает дополнительный штраф 0.2, но НЕ дисквалифицируется: если на
слайде больше ничего нет (слайд 8 Универсального — только цифра и подпись без
кегля), он по-прежнему выбирается, и это честно.

## Проверка

```
корпус: заголовком выбран показатель — было 3 слайда, стало 0 (кроме слайда,
        где других кандидатов нет)
study wordy: dop_orphans 3 → 5 (ложная висячая ушла)
2.1 у Универсального и Учебного: 4 → 3 — «2 длинных заголовка» было НЕДОСЧЁТОМ,
        их 3; итог 96.2 → 93.1 и 95.0 → 93.8
обычный бриф: 99.4 / 99.4 / 100.0 / 98.8 — без изменений
```

Просадка итога — это харнесс, ставший честнее, а не дека, ставшая хуже: третий
заголовок раньше был скрыт за «-40%». Проверил это явно, сравнив detail-строки
до и после.

Тесты: **233 passed** (+5). Первый падает на HEAD с `AssertionError: -40%`.

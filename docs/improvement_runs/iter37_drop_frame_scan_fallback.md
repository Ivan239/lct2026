# Итерация №37 — кадровый фолбэк контраста убран по замеру

## Генерация: пропущена по сети (двадцать второй раз подряд)

Прогон поднял **GigaChat-3-Ultra × Т—Ж Учебный** и упёрся в OAuth. Деки от
модели нет → **оценку 10.1 и взвешенный итог не выставлял.**

Чтобы было на что смотреть, собрал корпус офлайн: по деке на КАЖДОМ из пяти
реальных шаблонов, планы строит матчер (не я руками), 30 слайдов с рендерами.

## Что увидел глазами

Просмотрел деки survey-31 и survey-69, которые раньше не видел ни разу.
Тёмная брендовая канва, белый текст — читается; логотип, «BEYOND FRONTIERS»,
номера страниц на месте; KPI выровнены по базовой линии; дублей нет.

Два наблюдения:

1. **Декоративное сердце с канвы налезает на подпись KPI** («клиентов в месяц»,
   survey-31, слайд 3). Текст остаётся читаемым — сердце тонкое, контурное — но
   выглядит как случайность. Синтез размещает контент внутри контентных границ и
   про декор канвы ничего не знает.
2. **Ложная тревога, которую я снял замером.** На слайде-сравнении показалось,
   что колонки ужаты в левые 60% широкого слайда. Померил: колонки идут
   1.27→6.57 и 6.77→12.06 из 13.33in, то есть занимают всю полосу; «ужатость» —
   это короткий текст в широких боксах. Контентные границы тоже в порядке:
   86–93% канвы на всех пяти шаблонах. Чинить было нечего.

## Что чинил

Пункт очереди: кадровая проверка контраста осталась фолбэком после iter34 —
надо было проверить, приносит ли она что-нибудь. Замер по всему корпусу:

```
30 слайдов, пять шаблонов
боксовая проверка:  покрытие 6/6 на КАЖДОЙ деке, слайдов без данных — 0
фолбэк сработал:    0 раз
кадровая в одиночку на card-шаблоне: 5 флагов из 6, все ложные
```

То есть фолбэк включается ровно тогда, когда измерить текст невозможно, а на
корпусе такого не случилось ни разу; при этом там, где у него есть мнение о
card-макете, оно неверно в 5 случаях из 6. Ожидаемый вклад — ноль верных флагов
и ненулевой ложных. Убрал: слайд без измеримых боксов теперь честно попадает в
недостающее покрытие, а не получает выдуманный вердикт.

Заодно удалил `reconcile`. Он существовал, чтобы объявленная проверка ГАСИЛА
ложные срабатывания кадровой; кадровой в конвейере больше нет, а гасить
боксовый вердикт — измеренный по реально нарисованным глифам внутри их же
бокса — значит только терять верные флаги. Оставлять мёртвым опасно: его легко
подключить обратно по невнимательности. Теперь вердикт — ОБЪЕДИНЕНИЕ двух
проверок, каждая видит то, чего структурно не видит другая.

## Проверка

```
корпус (5 дек, все читаемы)   итог=[] на каждой, покрытие 6/6
эталон                         итог=[]
контроль (невидимый текст)     итог=[4]   ← поймано
сквозной evaluate_deck         контраст-флагов нет, покрытие полное
```

Тесты: **149 passed**. Тест про `reconcile` заменён на проверку нового правила,
включая `assert not hasattr(contrast, "reconcile")` — чтобы удаление было
зафиксировано, а не только описано.

## Честно про ценность

Это правка измерителя, а не деки: пользователь на слайдах разницы не увидит.
Ценность в том, что харнесс больше не может выдать ложный вердикт из источника,
который на корпусе не срабатывает вообще.

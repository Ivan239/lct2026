# Итерация №40 — синтез клонировал служебную страницу шаблона

## Генерация: пропущена по сети (двадцать пятый раз подряд)

Прогон поднял **GigaChat-2 × survey-31** и упёрся в OAuth. Деки от модели нет →
**оценку 10.1 и взвешенный итог не выставлял.** Работал на офлайн-корпусе.

## Сначала — эксперимент по вчерашней очереди

Пункт 1 был «переверстка после удаления графика». Прежде чем строить, проверил
посылку глазами: заполнил слайд survey-31, построенный вокруг графика, и
отрендерил. Слайд чистый и читаемый, но **нижние 40% пусты** — ровно как
предсказывал замер iter39. Синтезированный вариант на брендовой канве выглядит
собраннее, так что отбраковку таких слайдов не трогаю. Вывод прошлой итерации
подтверждён уже не числами, а рендером.

## Что увидел глазами

Посмотрел деку Т—Ж Универсального после правок iter38 — и слайд-сравнение
оказался **белым листом с текстом**: ни логотипа, ни «2025», ни бегущей темы,
ни номера страницы, ни фирменной жёлтой графики. На шаблоне, который узнаётся
по чёрному фону с жёлтым, это выглядит как чужой слайд.

## Разбор

```
канва всех трёх синтезированных слайдов: №11
слайд 11 шаблона = «Технический слайд»  — инструкция ДЛЯ ПОЛЬЗОВАТЕЛЯ шаблона:
   «В шаблоне использовали Roboto для заголовков и Inter для текста,
    скачайте шрифты по ссылке» + ссылки на Windows/macOS
```

То есть мы клонировали readme-страницу шаблона. Почему она выиграла:

```
кандидатов всего 3 (остальные отсеяны фильтром «есть фото» — фирменная
жёлтая графика 69% ширины):
   сл.11  контент-боксов=3  мебели=0   ← «Технический слайд»
   сл. 3  контент-боксов=5  мебели=3
   сл. 9  контент-боксов=9  мебели=3
фильтр «furniture-only» = ≤3 бокса → остаётся РОВНО один кандидат
```

## Реализация и один откат внутри итерации

Признак нашёлся в фоне: у readme-страницы `(248,248,248)`, и такой фон в деке
**ровно у одного слайда**, тогда как все дизайн-слайды чёрные.

Сначала отфильтровал кандидатов по ПРЕОБЛАДАЮЩЕМУ фону деки — и **откатил**:
замер показал, что это схлопывает все канвы в один цвет и убивает цветовую
ротацию (Моно с чередования синий/белый перешёл на сплошной белый). Признак
«фон-одиночка» точнее: у Моно белый честно занимает половину деки и остаётся
кандидатом.

Отсев одиночек стоит ДО фильтра «furniture-only» — иначе ранжирование ни на что
не влияет, потому что кандидат остаётся один (на этом первая версия и не
сработала).

## Проверка

```
Универсальный   канвы 11,11,11  →  3,3,3      ← дефект
Моно            10,11,10,11     →  без изменений (ротация цела)
Учебный         8,1,10          →  без изменений
survey-31/69                    →  без изменений
```

**Посмотрел рендер глазами**: чёрная брендовая канва, «2025 / ПЛАТФОРМА ПОТОК»
в шапке, номер «04», розовые акценты — слайд стал похож на свой шаблон.
Моно проверил отдельно: не изменился.

Тесты: **152 passed** (+1). Новый падает на HEAD с
`the readme page is being cloned as a canvas: {0: 11, ...}` и вторым
утверждением защищает ротацию Моно от того самого отката.

## Сравнение с прошлой итерацией

iter39 добавила видимость («шаблон предлагает 1 слайд из 31») — и именно
взгляд на деку Универсального после неё показал этот дефект. Здесь впервые за
несколько итераций правка меняет не геометрию, а ВЫБОР исходного материала, и
эффект на рендере самый заметный из недавних.

## Очередь

1. **[генерация] Фильтр «есть фото» отсекает фирменные канвы.** У Универсального
   из-за него осталось 3 кандидата из 12: жёлтая графика шире 1.2in. Теперь,
   когда контент умеет обходить декор (iter38), фильтр можно ослабить — но это
   отдельная проверка рендером.
2. **[классификация] Проверить на сети**, стал ли титул survey-31 «title».
3. **[генерация] Пустой низ** синтезированных слайдов на широких деках.
4. Пункт 11 плана — по просьбе пользователя не трогаем.

## Что сделано (нечётная — топ-1 дефект)

Топ-1 из iter122: на синтезированной KPI-доске (survey-31) цифры
переносились и ложились на подписи — «≤40 / мин.» на «простой», «18,4 млн /
₽» на «план бюджета»; в подписи — «перенесе/но».

**Причина:** `synthesize_stats_kpi` ставил каждую цифру плоскими 44pt в
колонку ширины слайда / число пар. Шесть пар — колонки по 1.5in. Правило
«цифра в одну строку» (iter115) действует только на нативном пути.

**Правило:** один кегль на всю доску — наибольший, при котором КАЖДАЯ цифра
одной строкой в своей колонке (`fit_font_size_single_line`, жирные метрики,
44 → не ниже 18); подписи — по самому длинному слову
(`cap_size_to_longest_word`), как у синтеза двух колонок.

**Рендер «до/после» глазами** (survey-31, шесть пар пакета «миграция CRM»,
боевой `generate` с `SYNTHESIZE`):
- до — «≤40 / мин.» и «18,4 млн / ₽» в две строки, вторая поверх подписи;
  «перенесе/но»;
- после — все шесть цифр в одну строку одним кеглем, подписи целые.

Пробник по умолчанию до/после — итоги те же (99.5 / 99.5 / 100 / 99.5),
рендеры не изменились: в базовом плане синтезированных KPI нет.

**Демо-картинку на слайде-списке (очередь №2) отложил:** правило «большая
картинка рядом со списком → скелет» задело бы брендовый арт Т—Ж
Универсального (слайд 2) и 3D-иллюстрации VK Tech 25/45/53. Записано в
бэклог — нужен признак, отличающий демо-снимок от арта.

# Итерация №62 — 1.1 перестал считать то, что дефектом не является

## Генерация: пропущена по сети (сорок седьмой раз подряд), за секунды

Деки от живой модели нет, оценка 10.1 не выставлялась.

## Пункт очереди из iter61

Вчера замер показал: `_overflows` — не мера дефекта. 32 из 79 боксов нетронутого
survey-31 «переполнены», 25 из них помечены `noAutofit`: дизайнер держит рамку
меньше текста намеренно, текст рисуется за ней, ничего не обрезается. Из-за
этого 1.1 ставил **3 из 5 нетронутым авторским декам** и одновременно **5 из 5**
нашей деке с четырёхкратным переполнением.

Спил текста может сделать ровно две вещи: уехать за край слайда (это 9.1 меряет
с iter60) или **лечь на другой текст**. Второе и стал считать.

## Порог не выдуман, а откалиброван

```
дизайнеры, 217 слайдов:  максимум 0.51 — survey-69 намеренно подсовывает

дефект iter59:           1.00 — подзаголовок целиком внутри текстовой полосы титула
наши текущие деки:       0
```

Порог 0.7 лежит с запасом с обеих сторон. Меряются ПОЛОСЫ ТЕКСТА, а не рамки:
рамочный вариант CLAUDE.md прямо запрещает (51 срабатывание на нетронутой
69-слайдовой деке), текстовый даёт 0 на четырёх шаблонах из пяти.

Наложение — дефект категориальный, поэтому оно НЕ растворяется в доле, а
ограничивает балл сверху, как в 9.1. Мелкий шрифт остаётся долей: он портит
деку постепенно.

## Проверка

```
восемь авторских шаблонов:  1.1 = 5 у всех (было 3-5), шума нет
дека с дефектом iter59:     1.1 = 2 и 9.1 = 2, итог 92.2
                            (98.8 до iter60 → 95.0 после iter60 → 92.2 сейчас)
наши текущие деки:          99.4 / 99.4 / 100.0 / 98.8 — без изменений
```

Тесты: **187 passed** (+4). На HEAD падают три: наложение оценивалось на 5,
а нетронутый survey-69 — на 4. Отдельный тест держит границу с другой стороны:
те же два блока, поставленные один под другим, дают чистую пятёрку, хотя титул
по-прежнему «переполняет» свою рамку.

## Сравнение с прошлой итерацией

iter61 нашла эту проблему замером и записала в очередь; эта итерация её закрыла.
Три итерации подряд про харнесс дали одну и ту же картину: критерий либо
заглушал настоящий дефект (9.1), либо шумел на авторской вёрстке (1.1 обеими
половинами). Итог по деке с реальным дефектом за три итерации уехал с 98.8 до
92.2 — не потому что дека стала хуже, а потому что её наконец начали мерить.

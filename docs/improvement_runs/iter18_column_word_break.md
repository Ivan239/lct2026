# Итерация №18 — колонки синтеза больше не рвут слова

## Генерация: снова пропущена по сети

OAuth-хост `ngw.devices.sberbank.ru:9443` по-прежнему таймаутит (`nc` не проходит,
два живых `access_token()` падают), `api.giga.chat:443` открыт. Деку не делали,
оценку 10.1 и взвешенный итог за итерацию не выставляли — нечего оценивать.

## Зато закрыл вопрос, который без сети был не проверить

Прошлая итерация научила харнесс ВИДЕТЬ невидимый текст, но причину я тогда
подтвердить не мог. Сейчас подтвердил офлайн: `generate()` сети не требует, так
что дефект воспроизводится синтетическим планом на настоящем Т—Ж Монохромном.

### Причина невидимого текста — подтверждена, фикс работает

Тема шаблона объявляет `dk1 = #213FFF` — это фирменный СИНИЙ, и он же идёт в
палитру как цвет текста (`observe_deck_style` цвета не наголосовал, только
шрифты). На белых слайдах шаблона синий текст верен. Но канва синтеза — слайд 4,
он СИНИЙ (32,56,248). Синий текст на синем фоне.

Воспроизведение на реальном шаблоне (канва — слайд 4, синий):

```
без canvas_backgrounds:  'Данные разбросаны…' → 213FFF   (синий на синем)
с canvas_backgrounds:    'Данные разбросаны…' → FFFFFF   (белый на синем)
```

Посмотрел оба рендера глазами: **без фикса пунктов списка на слайде физически
нет** — они есть в файле, но не видны. С фиксом весь текст белый и читается.
Фикс из прошлой итерации (`_recolor_for_canvas`) работает; дека, где дефект был
пойман (07-28), просто старше фикса (07-29).

## Что чинил в ЭТОЙ итерации

Тот же рендер сразу показал следующий дефект: заголовок колонки разорван
посреди слова — **«Разрозненнос / ть данных»**. Колонка — половина контентной
ширины, а на канве с фотографией справа bounds ещё уже; при зашитых 20pt слово
не влезает, и рендерер ломает его по буквам.

`synthesize_two_column_comparison` подбирал размер только по ВЫСОТЕ. Добавил
`cap_size_to_longest_word` (готовый примитив text_fit, написанный ровно для
этого — в его докстринге тот же класс дефекта: «Автоматизаци/я» на 51pt титуле)
для заголовков колонок и для пунктов; те же размеры пошли и в оценку высоты,
чтобы центрирование осталось согласованным.

Проверка на реальном шаблоне: заголовки ужались 20 → 14pt, рендер посмотрел
глазами — «Разрозненность / данных» переносится ПО СЛОВУ, разрыва нет, пункты
читаются. Тесты: **115 passed**.

## Очередь

1. **[генерация] Пустая правая половина** — колонки жмутся в левые 40% слайда,
   потому что bounds канвы исключают фотографию; справа под фото пусто. Ширину
   колонок стоит считать от реально свободной области, а не от половины bounds.
2. **[генерация] Устаревший номер слайда** — на клоне остаётся «05» из шаблона.
3. Ранее: служебный текст шаблона («ТЕМА ПРЕЗЕНТАЦИИ», «КОММЕНТАРИЙ»), потеря
   светлого фона на тёмной деке (Ultra × 31-слайд), рамка-скелет за границей.
4. Пункт 11 плана (ёмкость 3 колонки vs 4 мысли) — по просьбе пользователя не
   трогаем.

# Итерация №46 — синтез набирал заголовки одним кеглем на все шаблоны

## Генерация: пропущена по сети (тридцать первый раз подряд)

Прогон упёрся в OAuth. Деки от модели нет → **оценку 10.1 и взвешенный итог не
выставлял.**

## Что чинил

Из очереди оставался «пустой низ синтезированных слайдов». Полез искать причину
и нашёл более конкретную: синтез ставит заголовок **фиксированными 32pt**
независимо от шаблона. Замер тем же выборщиком титула, каким пользуется весь
пайплайн:

```
Универсальный   мода 42pt   (медиана 42)   мы: 32
Моно            мода 51pt   (медиана 51)   мы: 32   ← на треть мельче авторского
Учебный         мода 26pt   (медиана 26)   мы: 32   ← на пятую часть КРУПНЕЕ
survey-31       мода 40pt   (медиана 40)   мы: 32
survey-69       мода 32pt   (медиана 36)   мы: 32
```

То есть гипотеза «мы всегда мельче» неверна: на Учебном мы, наоборот, крупнее.
Правильная правка — не «увеличить», а взять кегль из самого шаблона.

## Реализация

`_template_title_pt(prs)` — мода размеров заголовков по слайдам шаблона.
Именно мода, а не среднее: проектная величина повторяется по деке (совпадает с
медианой на четырёх шаблонах из пяти), а одиночная дисплейная цифра — нет.
Меньше трёх заголовков — ответа нет, остаётся прежнее умолчание 32.

Значение кладётся в тему синтеза (`title_pt`) рядом с наблюдаемым стилем деки и
доходит до `_add_title`.

## Проверка

```
Моно      титул 32 → 51pt
Учебный   титул 32 → 26pt
```

**Посмотрел оба рендера глазами.** Моно: заголовок стал крупным, слайд читается
как настоящий слайд этого шаблона, а не как обобщённый. Учебный: 26pt выглядит
соразмерно карточке — уменьшение не сделало его слабым, оно совпало с тем, что
делает дизайнер.

Тесты: **158 passed** (+1). На HEAD падает импортом.

## Что тест поймал по дороге

Первая версия проверяла кегль на титульном слайде и упала: обложка
(`synthesize_title`) держит свои 40pt намеренно. Это отдельное решение —
настоящие обложки набирают САМЫМ КРУПНЫМ кеглем шаблона (82–120pt), а не
медианным. Переписал тест на контентный синтезатор, обложку записал в очередь.

## Сравнение с прошлой итерацией

Три предыдущие итерации чистили измеритель, и после них флагов не осталось —
поэтому эта вернулась к генерации. Правка того же рода, что и лучшие из
предыдущих: не придумывать величину, а измерить её у шаблона.

## Очередь

1. **[генерация] Обложка** набирается фиксированными 40pt, тогда как шаблоны
   отводят под неё 82–120pt. Отдельная величина — «максимальный заголовок
   шаблона», не медианный.
2. **[классификация] Проверить на сети**, стал ли титул survey-31 «title».
3. **[harness] Слайд без измеримых боксов** — помечать «непроверяемо».
4. Пункт 11 плана — по просьбе пользователя не трогаем.

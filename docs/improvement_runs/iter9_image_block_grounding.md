# Итерация №9 — слайд с картинкой перестал быть «Продукт X» (GigaChat-2-Pro)

- **Модель:** GigaChat-2-Pro, 8 слайдов, итог **93.4** (лучший за цикл).
- Порядок нарратива на этот раз верный: титул → проблема → «переходим к решению» →
  до/после → возможности → результаты → визуал → призыв. Структура 4.43.

## Что увидено глазами (и это РЕГРЕССИЯ от моего же прошлого коммита)

Слайд 7 (скелет изображения):
- заголовок «**Продукт X** — визуализация» — заглушечное имя вместо реального «Поток»;
- подпись «место под иллюстрацию продукта» — пустая, будущему генератору картинок
  бесполезна.

Судья этого НЕ отметил (изображения 5.0, контент 4.5) — поймал только глаз.

Корень (два слоя):
1. **У промпта `image_caption` вообще не было `__BRIEF__`** — модель получала только
   тему и физически не знала названия продукта. (Проверил все блок-промпты: бриф есть
   у title/bullet_list/stats_kpi/two_column; не было у image_caption.)
2. В принудительной вставке (iter: «гарантируем 1 слайд с картинкой») я захардкодил
   обобщённую тему «визуальная иллюстрация продукта», а модель ЭХОМ отражает тему в
   заголовок → «Продукт X — визуализация».

## Что реализовано и проверено

- В промпт `image_caption` добавлен бриф + прямой запрет заглушек («Продукт X», «ваш
  продукт») и требование конкретной СЦЕНЫ вместо общих слов.
- Тема вставляемого блока подобрана ЗАМЕРАМИ на живой модели (не на глаз): из
  кандидатов победила «как выглядит продукт в работе» — не протекает в заголовок.

Проверка (адресные вызовы блока + полный прогон с рендером):
- было: `«Продукт X — визуализация»` / `«место под иллюстрацию продукта»`;
- стало: `«Платформа «Поток» в действии»` / `«экран с единым дашбордом аналитики продаж»`
  — посмотрел рендер глазами: заголовок и подпись конкретные, рамка чисто под
  заголовком. Подпись теперь годится как промпт для будущей генерации картинки.
- Тесты: **106 passed**.

## Сравнение с прошлой итерацией

Прошлая гарантировала НАЛИЧИЕ слайда с картинкой; эта сделала его СОДЕРЖАТЕЛЬНЫМ.
Важный урок цикла: собственная правка может внести регрессию, которую метрики и судья
не видят — поймал только просмотр глазами.

## Очередь

1. `section_divider` и `closing` — единственные блок-промпты без брифа. Пока работают
   (тема достаточна: «Переходим к решению»), но это тот же класс риска — кандидат на
   проверку.
2. **[средний]** Смысловая редундантность stat/сравнение-слайдов (из iter1).
3. **[осторожно, ядро]** Вертикальный баланс: заголовок+контент в средней полосе,
   пустой низ — нужен продуманный редизайн, не автономная итерация.

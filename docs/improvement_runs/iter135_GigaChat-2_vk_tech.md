## Что сделано (нечётная — топ-1 дефект)

Топ-1 из iter134: оборванные пункты на T—Ж Универсальном («Наставники
проходят короткий», «Программой охвачены ключевые», «Продолжительность»).

**Причина** (проверена реальным вызовом того же блока — пакет «наставничество»,
слот 28 знаков): модель пишет пункты 41–51 знак, это больше потолка
«оставить целым» 39 (1.4 × 28). Обрезка по слову дала ровно деку iter134:
«Наставник закрепляется», «Срок программы», «Формат взаимодействия»,
«Наставники выбираются», «Обязательное обучение». Выбросить висящее
прилагательное — значит остановиться на слово раньше: 45 знаков в 28 без
потери смысла не обрезать.

**Правка** (`two_phase._shorten_overlong_items`): только для пунктов длиннее
потолка — ОДИН корректирующий вызов: «перепиши эти пункты короче N знаков
законченной фразой, сохранив цифры». Промпт — в файле
`prompts/shorten_items.v1.txt` (первый промпт в файлах, п. 9). Ответ берётся
только как улучшение (не длиннее потолка, не короче обрезки); сбой вызова —
обрезка, как раньше; сетевые ошибки — наверх (правило iter117).

**Вторая причина, найденная на том же вызове:** модель вернула «Наставники —
опытные сотрудники команд» (38 знаков, в пределах потолка), а наша обрезка
срезала его до «Наставники» — тире считалось границей клаузы. В пункте тире
заменяет сказуемое, после него — суть: «Без наставников — дольше адаптация»
(второй реальный вызов, пакет тот же) тоже шла как «Без наставников». Для
пунктов тире — не граница (`cut_at_clause_chars(..., dash=False)`); для
заголовков — как было.

**Проверка на записанных реальных ответах** (два вызова, повтор без
новых токенов):
- вызов 1: HEAD — пять обрубков; после — «Наставник у каждого нового
  сотрудника», «Программа действует 3 месяца», «Встречи с наставником — 3 часа
  в неделю», «Наставники — опытные сотрудники команд», «Обязательное обучение
  наставников»;
- вызов 2 (перебора нет, коррекции нет): «Без наставников» → «Без наставников
  — дольше адаптация».

**Рендер «до/после» глазами** (T—Ж Универсальный слайд 2, боевой путь
пробника): до — пять обрубков без фактов; после — пять цельных фраз с цифрами
одним кеглем (~20% мельче), иконки на месте.

Пробник по умолчанию до/после: итоги те же, все 30 рендеров побайтно совпадают.

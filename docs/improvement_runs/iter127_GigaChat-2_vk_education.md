## Что сделано (нечётная — топ-1 дефект)

Топ-1 из очереди iter125/126: пункты обрублены до одного слова — «Снижение /
Быстрый / Эффективное / Рост», «Обязательная», «Выход» (VK Tech 5, 7, 8 в
iter126; все списки слепого WorkSpace в iter125).

**Причина:** `get_item_char_budget` учит длину пункта у образца дизайнера в
слоте: `max(12, длина × 1.2)`. Правило делалось под T—Ж mono, где образец
«Название пункта» — настоящий пример длины однострочного слота. У VK
образцы — заглушки «Пункт», «Текст», «Заголовок»: бюджет 12, модель пишет
под него, обрезка по границе слова оставляет одно слово.

**Правило:** образец короче одной строки своего слота о длине ничего не
говорит — тогда предел — строка. Бюджет = max(по образцу, знаков в одной
строке слота при его кегле по метрикам шрифта, с `SINGLE_LINE_SAFETY`); кегль
унаследован — базовые 18pt (берёт меньше знаков, то есть осторожнее).
`build_spec` строит резолвер шрифтов шаблона (+0.5 с на VK Tech). Потолок 72
знака (`bullet_char_budget`) прежний.

**Замер по корпусу** (семьи списков, 50 слайдов): меняются только VK —
VK Tech 8: 12 → 28, 45: 12 → 20, 13–15: 14 → 22, 24: 14 → 51; VK Education
12/13/24 (однострочные широкие) → потолок 72; WorkSpace 12 → 19–47. T—Ж mono
(18), universal (28), study (18), survey — без изменений: там образец не
короче строки.

**Рендер «до/после» глазами** (VK Tech, боевой путь пробника: семья списков
сужена до одного слайда → `build_plan` → `generate`):
- слайд 8 «Содержание»: до — «Ручной сбор / Разные / Согласование»; после —
  «Ручной сбор показателей / Разные форматы выгрузок / Согласование занимало /
  Автоматический сбор» (обрезка — это фраза фикстуры пробника; модель в бою
  пишет под бюджет);
- слайд 45 (иконки + одна строка): до — «Разные», «Согласование», а четвёртый
  пункт, не резавшийся по границе слова, — мелким кеглем в две строки, и
  иконки-шестерёнки пропали (почему пропали — не разбирал); после — пункты по
  два слова, одним кеглем, иконки на месте.

Пробник по умолчанию до/после: итоги те же (99.5 / 99.5 / 100 / 99.5), все
24 рендера побайтно совпадают.

# Итерация №92 — бегущая шапка резалась по числу символов и всё равно не влезала

## Генерация: пропущена по сети (семьдесят седьмой раз подряд), за секунды

Деки от живой модели нет, оценка 10.1 не выставлялась.

## Что увидел глазами

Взял из очереди пункт «нужен случай, где рендерный перенос даёт ВИДИМЫЙ дефект»,
и худшим по всем декам оказалась сама бегущая шапка:

```
universal: 3.17 бокса, слайд 6, H=0.12in, отрисуется 0.38in — 'ПЛАТФОРМА УПРАВЛЕНЧЕСКОЙ ОТЧЁТ…'
study:     2.85 бокса, слайд 6, H=0.17in, отрисуется 0.48in — та же шапка
mono:      1.36 бокса, слайд 2 — заголовок
```

На рендере видно: шапка идёт в две строки, вторая висит НИЖЕ полосы chrome, где
у дизайнера пусто, и ломает линию «2025 — тема — 03».

## Разбор

Сверил с шаблоном, прежде чем чинить:

```
ШАБЛОН: бокс 1.85in H=0.12 8.0pt — «ТЕМА ПРЕЗЕНТАЦИИ» = 84pt при бюджете 133pt → одна строка
НАША:   тот же бокс                — 42-символьная обрезка   = 195pt          → две строки
```

`MAX_RUNNING_HEADER_CHARS = 42` — это догадка, не мерка бокса: слот держит
примерно два слова капсом, а не сорок два знака.

## Правка

Шапка обрезается по ШИРИНЕ бокса — слова отбрасываются с хвоста, пока строка с
многоточием не влезет в одну строку с запасом `SINGLE_LINE_SAFETY`. Символьный
лимит остался фолбэком для бокса, который нечем померить (нет шрифта/кегля).

```
universal: 'ПЛАТФОРМА УПРАВЛЕНЧЕСКОЙ…' 137pt/133 → 'ПЛАТФОРМА…' 59pt/133
study:                                            → 'ПЛАТФОРМА…' 74pt/128
переполнится при рендерном переносе: study 9 → 3, universal 15, mono 2 (без изменений)
итоги 99.5 / 99.5 / 100.0 / 99.5 — те же
```

**Посмотрел рендер глазами** (было/стало): шапка встала в одну строку по линии
«2025» и «03», как у дизайнера. Осталось одно слово из трёх — слот столько и
держит; две строки, вываливающиеся из полосы на КАЖДОМ слайде, были хуже.

## Промах, который поймал только замер

Первая версия мерила титул в исходном регистре, а пишется он капсом (`.upper()`
применяется ПОСЛЕ обрезки, регистр берётся у шаблонного плейсхолдера). Кириллица
капсом шире: «ПЛАТФОРМА УПРАВЛЕНЧЕСКОЙ…» = 137pt при бюджете 133 — правка
«сработала» и всё равно переносила. Мерить надо строку в том виде, в каком её
ОТРИСУЮТ; теперь преобразование регистра передаётся в замер.

# Итерация №47 — обложка: авторский кегль и починенная за ним компоновка

## Генерация: пропущена по сети (тридцать второй раз подряд)

Прогон упёрся в OAuth. Деки от модели нет → **оценку 10.1 и взвешенный итог не
выставлял.**

## Что чинил

Пункт из очереди прошлой итерации: обложка набирается фиксированными 40pt.
Замер по слайду 0 всех пяти реальных шаблонов:

```
Универсальный  42pt     Моно 68pt     Учебный 34pt     survey-31 92pt     survey-69 92pt
контентный титул (iter46):  42 / 51 / 26 / 40 / 32
```

То есть обложка у дизайнеров действительно громче контентного заголовка (на
двух шаблонах из трёх Т—Ж и вдвое с лишним на боевых деках), а наши 40pt
неверны на четырёх шаблонах из пяти — на survey это меньше половины авторского.

`_template_cover_pt` берёт кегль титульного бокса слайда 0. Отдельно от
`_template_title_pt` намеренно: это разные величины дизайна.

Добавил и ограничение по длинному слову — при 92pt без него заголовок рвался бы
по буквам (урок iter18/iter25). На survey оно и сработало: 92 → 88pt.

## Регресс, который я внёс и увидел на рендере

Первый рендер после правки: **подзаголовок напечатан прямо поверх заголовка**.
«Итоги внедрения за квартал» прошло между «Платформа» и «Поток».

Причина: подзаголовок стоял на жёстких 60% высоты слайда. Это было чисто ровно
для однострочного заголовка в 40pt и ни для чего больше — при 88pt заголовок
переносится на две строки и кончается на 5.94in, а подзаголовок начинался на
4.50in.

Тот же урок, что и в iter35: отступ считать от РЕАЛЬНОГО бокса, а не от доли,
которая случайно работала при одном кегле. Высота титульного бокса теперь
считается по тексту, подзаголовок ставится под ним.

```
после правки: титул 2.85–5.94, подзаголовок 6.14–7.04 — не пересекаются
```

**Посмотрел рендер глазами**: обложка набрана в масштабе шаблона, две строки
заголовка, подзаголовок чисто под ними.

Тесты: **159 passed** (+1). Тест фиксирует именно эту связку: при кегле 92
подзаголовок обязан начинаться ниже конца заголовка.

## Честно про порядок

Правка кегля без правки компоновки — регресс, и я бы его отгрузил, если бы
судил по числам: ёмкости, размеры и тесты были зелёные. Увидел только на
рендере. Это ровно то, ради чего в цикле стоит требование смотреть глазами.

## Сравнение с прошлой итерацией

iter46 сделала то же самое для контентных заголовков и прошла без сюрпризов;
здесь тот же приём вскрыл спрятанное допущение в соседнем коде. Обе итерации об
одном: не назначать величины, а брать их у шаблона.

## Очередь

1. **[классификация] Проверить на сети**, стал ли титул survey-31 «title» —
   единственный пункт, который нельзя закрыть офлайн.
2. **[harness] Слайд без измеримых боксов** — помечать «непроверяемо».
3. **[генерация] Кегли ТЕЛА** (списки, KPI, колонки) по-прежнему фиксированные
   15/20pt на все шаблоны — та же болезнь, что была у заголовков.
4. Пункт 11 плана — по просьбе пользователя не трогаем.

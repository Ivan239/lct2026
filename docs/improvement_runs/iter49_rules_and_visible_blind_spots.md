## Что сделал

**1. Записал в `CLAUDE.md` правила, добытые за последние ~15 итераций.** Файл
грузится в каждую сессию, а половина дорогих находок жила только в отчётах:

- нативный и клон-путь расходятся; фикс, проверенный на одном, на другом может
  быть мёртв (перенумерация страниц и бегущая тема так молчали несколько
  итераций);
- величины типографики измерять у шаблона, а не назначать — с числами по пяти
  шаблонам и с оговоркой, что для ТЕЛА такого источника нет (проверено, мода
  ловит мелкие подписи, по ролям выборки вырождаются);
- меняя кегль, пересчитывать компоновку: подзаголовок обложки стоял на жёстких
  60% высоты и при авторских 88pt напечатался поверх заголовка — при зелёных
  числах и тестах;
- харнесс не должен судить авторский макет: три подряд ложные тревоги одного
  рода (chrome как основной текст, поле шаблона как нарушение зоны, фирменный
  двухстрочный заголовок как висячая строка);
- молчащий измеритель читается как «всё хорошо».

**2. Починил ровно этот последний случай уровнем выше.** Отчёт печатает только
критерии с баллом ≤ 3. Примечание «контраст не проверен» живёт в детали 1.1, а
у здоровой деки 1.1 = 5 — то есть предупреждение, добавленное в прошлой
итерации, не увидел бы никто. Теперь у отчёта есть отдельный раздел:

```
## Не проверено
- контраст на слайдах [1]: текст лежит на картинке, фона для замера нет — смотри глазами
```

На здоровой деке раздел не появляется.

## Что сделано (чётная — шаг по ТЗ, п. 2)

Шаг бэклога «факты пакета — эталон для проверки "все цифры есть в исходных
материалах"». Пункт Приложения 1, который до сих пор проверял только глаз.

`dop_numbers_sourced` — детерминированный критерий в категории «Контент»:

- **Эталон** — `numbers` контент-пакета (`evaluate_deck(source_numbers=…)`,
  прокинут через `run_iteration`), без пакета — цифры брифа.
- **Где ищет:** весь контентный текст слайда так, как его видит читатель —
  группы раскрываются, ячейки таблиц читаются (оба места невидимы для
  верхнеуровневых критериев, iter105/iter107). Колонтитулы (номер страницы,
  «2025») пропускаются по боксу верхнего уровня.
- **Как сравнивает:** по значению — «+25 %» в брифе и «25%» на слайде одно
  утверждение; знак и единица — перефразировка, не выдумка. Голое целое до 10
  без знака и единицы («01», «шаг 3») — порядковое, не утверждение; «3 дня»,
  «+4 шт.» — утверждения.
- **Шкала категориальная**, не доля (урок 9.1): один выдуманный факт — 3,
  два-три — 2, четыре и больше — 1. В детали — какие цифры и на каких слайдах.
- Попутно: «недели» добавлены в единицы `extract_numbers` — «2 недели»
  распознавались как голое «2» и в проверку не попадали.
- **Пробник** сверяет деку с цифрами СВОЕЙ фикстуры (`_plan_numbers`): цифра,
  которой нет в плане, — остаток шаблона или испорченное генератором число.

**Проверено:**
- на этой деке: 20 цифр, 1/5, деталь называет все по слайдам — включая 8
  невидимых на слайде 7;
- старый корпус: 5/5 на всех четырёх, итоги пробника не сдвинулись
  (99.5 / 99.5 / 100 / 99.5). Критерий не беззубый: с пустым эталоном он
  находит в тех же деках 1–3 цифры фикстуры («−40%», «+18», «4 дня»);
- сами шаблоны: VK Tech — 15 демо-цифр дизайнера, VK Education — 72,
  WorkSpace — 0. Если такая цифра утечёт в деку, критерий её назовёт.

**Следствие для цикла:** канонический бриф цифр не содержит, поэтому пока цикл
генерирует по нему, критерий будет стоять на 1 — это правда о деках, а не
ложная тревога. Лечится следующим шагом бэклога: генерация по контент-пакетам.

Добавлены строки в `docs/evaluation_rubric.md` — для этого критерия и для
`dop_no_placeholders` (iter102, там его не было).

3. Стиль синтезированных заголовков из шаблона.
4. Контент В карточки канвы, а не поверх пустых подложек.
5. Пустой элемент шаблона на закрытии (белый квадрат под QR).

# Итерация №90 — флаги дублей оказались свойством моей фикстуры

## Генерация: пропущена по сети (семьдесят пятый раз подряд), за секунды

Деки от живой модели нет, оценка 10.1 не выставлялась.

## Что нашёл, идя за цветовой ротацией

Смотрел клоны Учебного и заметил: карточки идут «жёлтая, синяя, синяя, синяя,
бежевая, бежевая, бежевая, бежевая» — ротация из четырёх цветов (уверенность
профиля 1.0) сломана.

Разобрал до причины и **отказался чинить**:

```
семейство bullet_list у Учебного: ОДИН слайд (2, синий) — других списков в шаблоне нет
цвет карточки задан ПОЛНОЭКРАННОЙ КАРТИНКОЙ (фон Т—Ж это растр)
```

То есть перекрасить нечего: нужна подмена изображения фона из слайда нужного
цвета — существенная правка с копированием частей пакета. Записал в очередь как
есть, с замером.

## Что оказалось важнее

Деки с повтором стабильно показывали «слабые: 2.3 (3 повторяющихся заголовка),
dop_no_dup_slides». Я читал это как свойство оси повторов. На деле мой
`repeat_outline` подавал ОДИН И ТОТ ЖЕ блок три раза — дека была дублирующей по
построению, и критерии дублей срабатывали на фикстуре.

Теперь повторы несут разный контент:

```
--repeat 3: 91.2–92.2 → 100.0 / 100.0 / 100.0 / 100.0, слабых нет
обычный бриф: без изменений
```

## Первая версия варьирования была нечестной

Я приписывал к пунктам суффикс «(что дальше)» — и его срезала обрезка по бюджету
слота (28 символов). Слайды выходили с ОДИНАКОВЫМИ пунктами под разными
заголовками: фикстура переставала ронять проверку дублей, не став при этом
разной. Заменил пункты целиком; тест отдельно проверяет, что различие переживает
обрезку до 28 символов.

Тесты: **266 passed** (+2).

## Сравнение с прошлой итерацией

iter89 чинила критерий, эта — вход, на котором критерий срабатывал. Второй раз за
три итерации выясняется, что «слабое место продукта» было свойством измерения:
сначала пробник не передавал роли, теперь подавал дубли. Ось повторов после
обеих правок наконец говорит о продукте.

   перекраски нет.
2. **[классификация] Прогон со связью** — потолок survey-31 ~10–12 из 31.
3. Пункт 11 плана — по просьбе пользователя не трогаем.

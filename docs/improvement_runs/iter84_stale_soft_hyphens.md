# Итерация №84 — заголовок рвался посреди слова из-за устаревших мягких переносов

## Генерация: пропущена по сети (шестьдесят девятый раз подряд), за секунды

Деки от живой модели нет, оценка 10.1 не выставлялась.

## Что увидел глазами

Слайд-список mono на пресете `wordy`:

```
Что мешало
собирать упра-
вленческую
отчётность вовремя
```

Заголовок разорван посреди слова с видимым дефисом — то, с чем проект воюет с
iter18.

## Разбор: не то, что казалось

Сперва решил, что не сработал кап по длинному слову. Замер показал обратное:

```
бокс 4.08in, бюджет 293.9pt, кегль 28pt
«управленческую» = 232.6pt — ВЛЕЗАЕТ с запасом
в тексте стоят МЯГКИЕ ПЕРЕНОСЫ: 'упра\xadвленче\xadскую'
```

Мягкие переносы ставит филлер, когда слово не влезает при ЕГО кегле (это
осознанный аварийный выход: видимый дефис лучше слова, обрубленного посреди
буквы). Потом `enforce_text_fits` ужимает текст дальше — и на новом кегле слово
влезает, а переносы остаются. Рендер предпочитает разорвать по мягкому переносу,
а не переносить слово целиком, поэтому устаревший перенос продолжает рвать
слово, которому это больше не нужно.

## Правка

После финального фиттинга мягкие переносы снимаются с тех слов, которые уже
влезают в свой бокс при своём итоговом кегле.

```
до:    'Что мешало собирать упра\xadвленче\xadскую отчётность вовремя'
после: 'Что мешало собирать управленческую отчётность вовремя'
```

**Посмотрел рендер глазами**: слово целиком на своей строке, дефиса нет. Итоги
дек не изменились (перенос — дефект, который харнесс не меряет).

Тесты: **245 passed** (+2). Второй тест держит аварийный выход: в боксе 1.2in то
же слово переносы СОХРАНЯЕТ — там они всё ещё делают свою работу. Проверка на
HEAD сделана сквозь пробник: титул выходит с `\xad` внутри.

## Сравнение с прошлой итерацией

iter83 закрывала методическую дыру (какой прогон я читаю); эта — дефект,
который виден только на рендере и не ловится ни одной проверкой. Шестой дефект
подряд из пресета `wordy`, и снова первая гипотеза («не сработал кап») оказалась
неверной — спасло то, что замерил ширину слова, а не поверил объяснению.

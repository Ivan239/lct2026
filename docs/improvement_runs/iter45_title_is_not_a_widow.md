# Итерация №45 — заголовок в две строки считался висячей строкой

## Генерация: пропущена по сети (тридцатый раз подряд)

Прогон упёрся в OAuth. Деки от модели нет → **оценку 10.1 и взвешенный итог не
выставлял.**

## Что чинил — последний флаг корпуса

У Т—Ж Монохромного оставался `dop_orphans` = 3: «1 висячая строка из 2
многострочных абзацев». В очереди значилось «нужен минимальный размер выборки»,
но прежде чем добавлять порог — нашёл, ЧТО именно засчитано:

```
сл.1  строк=2  сирота=True  68pt, ширина 7.05in
      'Платформа Поток'   ← это ЗАГОЛОВОК
```

**Посмотрел рендер глазами**: «Платформа / Поток» на две строки — ровно тот
приём, которым набран и сам шаблон («Заголовок / слайда» на его титульном
слайде). Не дефект, а фирменная типографика.

То есть проблема была не в размере выборки, а в том, что правило про висячие
строки — правило для ОСНОВНОГО текста — применялось к дисплейным заголовкам.
Замер по корпусу: на пять дек ровно одна «сирота», и это заголовок.

## Реализация

Заголовок слайда исключён из подсчёта сирот. Ограничение честное и его стоит
знать: настоящая висячая строка В ЗАГОЛОВКЕ теперь не будет поймана — но
двухстрочный заголовок с одним словом на второй строке в этих шаблонах норма, а
не отклонение.

```
Моно            97.5 → 99.4, флагов нет
остальные       без изменений
```

## Состояние корпуса после трёх итераций чистки измерителя

```
Универсальный  99.4    Моно 99.4    Учебный 100.0    survey-31 99.4    survey-69 99.4
```

Детерминированная часть больше не находит ничего ни на одной деке — и это
похоже на правду: на рендерах я тоже не вижу переполнений, обрезок и наложений.
Оговорка та же, что всегда: это композит по геометрии и контрасту, он НЕ равен
впечатлению «показать не стыдно».

## Проверка

Тесты: **157 passed** (+1). Тест проверяет обе стороны: заголовок в две строки
не считается сиротой, а настоящая висячая строка в теле ловится. На HEAD падает
с «the title was counted as a widow».

Хвост для фикстуры подобрал ЗАМЕРОМ, а не на глаз: короткие хвосты («и», «да»)
сироты не дают вовсе — они умещаются на предыдущей строке.

## Сравнение с прошлой итерацией

Третья подряд правка измерителя, и все три одного рода: харнесс судил авторский
макет по своей мерке — chrome как основной текст (iter43), собственное поле
шаблона как нарушение безопасной зоны (iter44), фирменный двухстрочный заголовок
как висячую строку (эта). Дальше чистить, похоже, нечего: флагов не осталось.

3. **[генерация] Пустой низ** синтезированных слайдов на широких деках — самое

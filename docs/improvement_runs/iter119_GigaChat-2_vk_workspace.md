  — сетка «до/после» 2×3 не по ячейкам. **Слайд 2** — «Раздел продолжается…»
  и пустые рамки. **Слайд 7** — «разработчи/ка» (харнесс поймал).

## Что сделано (нечётная — топ-1 дефект с НЕслепого шаблона)

Топ-1 — находка пробника iter118 (T-Zh mono, дека на 12 слайдов): список на
слайде с четырьмя колонками напечатан 51pt в боксе ЗАГОЛОВКА, заголовок —
мелко в колонке. Харнесс его не видел (99.5).

**Причина — две ступени.**
1. Слайд: заголовок-бокс сверху («Заголовок / слайда» — ДВА абзаца, 51pt),
   под ним четыре колонки «год 51pt + подпись 10pt». Подписи — готовые слоты
   списка, но `_find_slot_boxes` их не видел: `_uniform_axis` считал шаги по
   координатам, ОКРУГЛЁННЫМ вниз до 0.1in. Настоящие левые края 0.31 / 2.67 /
   5.14 / 7.49in — шаги 2.36 / 2.47 / 2.35 (разброс 0.12, в допуске 0.15);
   округлённые 0.3 / 2.6 / 5.1 / 7.4 — шаги 2.3 / 2.5 / 2.3 (разброс 0.2, «не
   сетка»). Округление само вносит до 0.2in ошибки в разность шагов — больше
   всего допуска.
2. Без слотов филлер берёт телом бокс с наибольшим числом абзацев — это
   двухабзацный заголовок.

**Правило:** шаги считаются по реальным координатам (минимум в корзине),
корзины — только для счёта позиций. По всему корпусу (8 шаблонов) меняется
ровно один слайд — этот (слотов 0 → 4, ёмкость 2 → 4).

**Рендер «до/после» глазами** (пробник `--deck-size 12 --only mono`):
- до — «Проверка / Обучение» 51pt в боксе заголовка, заголовок мелко в
  колонке;
- после — заголовок в своём боксе наверху, три пункта в подписях колонок,
  лишняя колонка снята. Итог пробника mono-12: 99.5 → 100.
- Над подписями пусто там, где у дизайнера стояли годы 51pt — известный
  дефект «слоты канвы заполнены частично».

**Базовый пробник (6 слайдов) не сдвинулся:** 99.5 / 99.5 / 100 / 99.5, все
24 рендера побайтно одинаковы.

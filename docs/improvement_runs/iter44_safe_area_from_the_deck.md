# Итерация №44 — безопасная зона мерилась от константы, а не от шаблона

## Генерация: пропущена по сети (двадцать девятый раз подряд)

Прогон поднял **GigaChat-2 × Т—Ж Универсальный** и упёрся в OAuth. Деки от
модели нет → **оценку 10.1 и взвешенный итог не выставлял.**

## Что чинил — топ очереди, найденный замером в iter43

У Т—Ж Монохромного висел флаг «9 боксов ближе 2% к краю». Разбор:

```
слайд 10in, безопасная зона 2% = 0.20in
боксы деки стоят на L = 0.19–0.20in
```

То есть проверка объявляла небезопасным СОБСТВЕННОЕ поле шаблона: контент стоит
там, где его поставил дизайнер, на каждом слайде.

Замер распределения по всему корпусу:

```
Универсальный  минимальный отступ 3.9%   = 10-й перцентиль
Моно                              1.9%   = 10-й перцентиль
Учебный                           3.9%   = 10-й перцентиль
survey-31                         3.3%   = 10-й перцентиль
survey-69                         2.5%   = 10-й перцентиль
```

Минимум везде совпадает с 10-м перцентилем — значит боксы СТОЯТ на проектном
поле, а не расползаются к краю. Мера «2% от слайда» просто не совпала с выбором
одного из дизайнеров.

## Реализация

Бокс считается вышедшим из безопасной зоны, если он ближе к краю, чем **и**
общее правило (2%), **и** собственное поле деки. Поле деки — МОДА отступов,
округлённых до 0.05in: повторяющееся поле это решение дизайнера, а одиночный
уехавший бокс модой не станет и по-прежнему ловится.

```
Моно            91.2 → 97.5, флаг снят
остальные       без изменений
```

## Главная проверка — что критерий не выключен

Смягчать проверку легко; смысл только в том, чтобы она продолжала ловить
настоящее. Сдвинул один бокс реальной деки Моно на 0.05in от края:

```
вердикт: «1 боксов ближе к краю» — поймано
```

Тесты: **156 passed** (+1). Тест проверяет обе стороны на синтетической деке
(без LibreOffice): при поле 0.19in флагов ноль, а один бокс, уехавший на 0.05in,
ловится. На HEAD он падает с «9 боксов» — тем же числом, что и на реальной деке.

Заодно поправил формулировку в отчёте: она обещала «ближе 2%», хотя порог теперь
может быть и собственным полем деки.

## Сравнение с прошлой итерацией

iter43 убрала из подсчёта chrome, здесь — вторая ложная тревога того же
происхождения: харнесс судил авторский макет по своей мерке. После двух правок
детерминированная часть на четырёх деках из пяти не находит ничего, и это
похоже на правду — на рендерах я тоже ничего не вижу.

У Моно остался единственный флаг: `dop_orphans` = 3, «1 висячая строка из 2
многострочных абзацев». Доля от двух — статистика ни о чём; сам перенос надо
посмотреть глазами, прежде чем считать дефектом.

## Очередь

1. **[harness] `dop_orphans` на выборке из двух абзацев** даёт 3 балла из-за
   доли 1/2. Нужен минимальный размер выборки, иначе критерий шумит.
2. **[классификация] Проверить на сети**, стал ли титул survey-31 «title».
3. **[harness] Слайд без измеримых боксов** (текст поверх фото) — помечать
   «непроверяемо», а не молчать.
4. Пункт 11 плана — по просьбе пользователя не трогаем.

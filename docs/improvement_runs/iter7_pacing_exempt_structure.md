# Итерация №7 — темп/распределение считать по контентным слайдам (GigaChat-2)

- **Модель:** GigaChat-2 (base) — и снова **без краша** (сеть безопасности из iter4 работает в бою).
- Дека: 7 слайдов, итог 91.2. Bg/контраст/вдовы держатся.

## Что увидено глазами + что числа завышали

Слайд 3 — секционный дивайдер «Разделяй и властвуй»: одна фраза (19 симв.) на весь
слайд. Это нормально — дивайдер разрежён ПО ДИЗАЙНУ. Но `dop_distribution` показал
CV=0.74 (балл 3), худшее детерминированное. Разобрал по слайдам:

```
слайд 1 (title)     103 симв.
слайд 2             156
слайд 3 (divider)    19   ← структурный, разрежён намеренно
слайд 4             148
слайд 5             126
слайд 6             375
слайд 7 (closing)    63   ← структурный
```

Дивайдер (19) и закрытие (63) РАЗДУВАЮТ разброс. Без них CV падает 0.74 → 0.50. То
есть метрика штрафовала деку за наличие СТРУКТУРЫ (дивайдер/закрытие обязаны быть
разрежёнными) — ровно то, что `qa.geometry.find_sparse_slides` уже исключает через
`SPARSE_EXEMPT_ROLES`, а мои `dop_distribution`/`dop_pacing` — нет.

## Что реализовано и проверено

`deterministic`: `dop_distribution`/`dop_pacing` теперь считают разброс ТОЛЬКО по
контентным слайдам (исключая `title`/`section_divider`/`closing` по `slide_roles`,
которые loop и так передаёт). Без ролей — фолбэк на все слайды (обратная совместимость).
Побочно исправлен латентный баг: char- и shape-счётчики фильтровались НЕЗАВИСИМО и
зипались — пары могли рассинхрониться; теперь читаются с ОДНИХ слайдов.

Проверка:
- На боевой деке с ролями: `dop_distribution` CV 0.74 → **0.50** (балл 3 → 4),
  `dop_pacing` 0.62 → **0.39** (3 → 4). Без ролей — не изменилось (0.74).
- Роли `section_divider`/`title`/`closing` из `OUTLINE_ROLES` точно совпадают с
  `SPARSE_EXEMPT_ROLES` → в бою исключение срабатывает.
- Тест `test_pacing_excludes_structural_sparse_slides` (дивайдер не топит темп).
- Тесты: **103 passed**.

Это НЕ игра с метрикой: рубрика «нет слайдов с слишком малым объёмом» не про дивайдеры
(у них малый объём — норма); честная оценка — равномерность КОНТЕНТНЫХ слайдов.

## Сравнение с прошлой итерацией

iter6 — вдовы (продукт). iter7 — честность метрики темпа (harness): больше не штрафуем
деку за структурные разрежённые слайды. Плюс подтвердил в бою iter4 (GigaChat-2 base
не упала).

## Очередь

0. **[осторожно, ядро] Вертикальный баланс синтеза** — разобрал геометрию: `_centered_top`
   центрирует короткий блок → зазор под заголовком. Но это НАМЕРЕННО (альтернативу
   «прижать к заголовку» осознанно отвергли), и на 3-буллетном слайде любое положение
   выглядит пусто (проблема плотности контента, не позиционирования). Безопасной узкой
   правки по-прежнему нет — нужен продуманный редизайн, не автономная итерация.
1. **[средний] Смысловая редундантность / повторы идей** (судья стабильно: 3.4, 5.2, 6.x) —
   контентное качество аутлайна; кандидат — правка промпта аутлайна (мягкий рычаг).

# Рубрика оценки презентации

Единый чек-лист для оценки сгенерированной (или любой) презентации — как для ручного
ревью, так и для промпта LLM-судьи. Оценивается по каждому критерию отдельно,
итог — взвешенная сумма по категориям.

## Шкала оценки (для каждого критерия)

- **5 — Отлично.** Полностью соответствует требованиям.
- **4 — Хорошо.** Есть небольшие недочеты, не влияющие на восприятие.
- **3 — Удовлетворительно.** Недочеты заметны, но слайд остается рабочим.
- **2 — Плохо.** Существенные проблемы, требуется доработка.
- **1 — Очень плохо.** Критерий практически не выполнен.
- **N/A** — критерий неприменим к конкретному слайду.

## 1. Визуальный дизайн

### 1.1 Читаемость текста
Оценивается: текст хорошо читается; достаточный размер шрифта; хороший контраст; фон не мешает.
- 5 — Все читается без усилий.
- 3 — Есть отдельные сложночитаемые элементы.
- 1 — Большая часть текста читается плохо.

### 1.2 Перекрытие текста изображениями
Оценивается: изображения не закрывают важный текст; допускается частичное декоративное
наложение; смысл текста остается полностью понятным.
- 5 — Перекрытия либо отсутствуют, либо выглядят дизайнерским приемом.
- 3 — Несколько слов частично закрыты.
- 1 — Текст невозможно прочитать.

### 1.3 Баланс композиции
Проверяется: нет ощущения перегруженности; элементы распределены равномерно; взгляд
естественно движется по слайду.

### 1.4 Использование свободного пространства
Проверяется: нет огромных пустых областей; нет чрезмерной плотности.

### 1.5 Выравнивание элементов
Проверяется: объекты стоят по сетке; одинаковые отступы; ничего не «прыгает».

### 1.6 Визуальная иерархия
Должно быть понятно: заголовок; ключевая мысль; детали.

### 1.7 Единый стиль
Проверяется: одинаковые шрифты; одинаковые формы; единая палитра; единый стиль иконок.

### 1.8 Цветовая гармония
Проверяется: цвета сочетаются; нет случайных ярких цветов; важные элементы выделены.

## 2. Заголовки

### 2.1 Длина заголовка
Хорошо: до 8–10 слов; желательно до 60 символов.
Плохо: «Основные преимущества внедрения современных технологий в процесс...»

### 2.2 Информативность
После прочтения заголовка понятно, о чем слайд.

### 2.3 Уникальность
Не должно быть десяти слайдов с названием «Вывод».

## 3. Текст

### 3.1 Количество текста
Не должно быть стены текста. Хорошо: короткие абзацы; списки; выделения.

### 3.2 Структура
Есть: абзацы; списки; таблицы при необходимости.

### 3.3 Ясность
Нет сложных конструкций.

### 3.4 Отсутствие повторов
Не повторяются одинаковые мысли.

### 3.5 Грамматика
Нет: опечаток; орфографических ошибок; пунктуационных ошибок.

## 4. Изображения

### 4.1 Соответствие теме
Изображение помогает понять материал.

### 4.2 Качество
Нет: пикселизации; артефактов ИИ; обрезанных объектов.

### 4.3 Соотношение размеров
Картинки не слишком большие и не слишком маленькие.

### 4.4 Подписи
Если изображение требует пояснения — оно есть.

### 4.5 Избыточность
Нет бессмысленных декоративных картинок.

## 5. Контент

### 5.1 Соответствие запросу
Слайды отвечают поставленной задаче.

### 5.2 Полнота
Не пропущены ключевые темы.

### 5.3 Логика
Есть последовательность: проблема → анализ → решение → вывод.

### 5.4 Фактическая корректность
Нет ошибок в данных.

### 5.5 Последовательность терминов
Одни и те же понятия называются одинаково.

### 5.6 Отсутствие галлюцинаций
ИИ не придумывает: цитаты; исследования; статистику; источники.

## 6. Структура презентации

### 6.1 Логичный порядок слайдов
Нет резких переходов между темами.

### 6.2 Связность
Каждый следующий слайд продолжает предыдущий.

### 6.3 Завершенность
Есть вывод или итог.

## 7. Инфографика

### 7.1 Корректность диаграмм
Диаграммы отражают данные.

### 7.2 Понятность
Без объяснений понятно, что показывает график.

### 7.3 Читаемость подписей
Подписи не перекрываются.

## 8. Адаптация под аудиторию

### 8.1 Соответствие уровню аудитории
Материал не слишком сложный и не слишком простой.

### 8.2 Соответствие стилю
Например: академический; деловой; маркетинговый; инвестиционный.

## 9. Техническое качество

### 9.1 Нет выходящих за границы объектов
Ничего не обрезано.

### 9.2 Нет наложений элементов
Иконки не перекрывают таблицы и текст.

### 9.3 Консистентность
На всех слайдах: одинаковые поля; одинаковые размеры заголовков; одинаковые стили.

### 9.4 Корректное использование анимации (если есть)
Анимация не отвлекает.

## 10. Общая полезность

### 10.1 Готовность без ручной правки
- 5 — можно сразу показывать.
- 4 — нужны косметические изменения.
- 3 — потребуется 15–30 минут правок.
- 2 — нужна серьезная переработка.
- 1 — проще сделать заново.

## 11. Дополнительные критерии для оценки ИИ

- Следование пользовательскому промпту.
- Соблюдение фирменного стиля (брендбук, цвета, шрифты).
- Корректное использование шаблона презентации.
- Равномерное распределение информации по слайдам.
- Отсутствие дублирующихся слайдов.
- Корректное разбиение текста на несколько слайдов.
- Уместность выделений (жирный, цвет, акценты).
- Корректность автоматических переносов строк.
- Использование качественных иконок вместо случайного клипарта.
- Согласованность стиля изображений (например, все фотографии или все иллюстрации).
- Отсутствие «сирот» и «висячих» строк (одиночных слов на новой строке).
- Соблюдение безопасных полей: важные элементы не находятся слишком близко к краям.
- Умеренное количество объектов на слайде (без визуального шума).
- Сохранение единого темпа презентации: нет слайдов с чрезмерно большим или слишком
  малым объемом информации.

## Итоговая система оценки

Категории группируются с весами, внутри категории выставляется средний балл по
критериям (от 1 до 5), затем рассчитывается итоговая взвешенная оценка по
100-балльной шкале.

| Категория                     | Вес  |
|--------------------------------|------|
| Визуальный дизайн              | 25%  |
| Читаемость и типографика       | 15%  |
| Контент                        | 25%  |
| Структура презентации          | 10%  |
| Изображения и инфографика      | 10%  |
| Следование запросу              | 10%  |
| Техническое качество           | 5%   |

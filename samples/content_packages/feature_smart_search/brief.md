# Умный поиск в корпоративном мессенджере

Питч новой фичи для продуктового комитета: просим одобрить раскатку умного поиска
на всех пользователей мессенджера.

Проблема: сотрудники тратят много времени, чтобы найти нужное сообщение или файл
в рабочих чатах; обычный поиск ищет только точное совпадение слов.

Решение: поиск по смыслу запроса, по вложениям и по участникам чата, с подсказками
при наборе. Работает внутри мессенджера, без отдельного окна.

Что показать: проблему в цифрах, как работает фича, результаты шестинедельного
пилота на 1 200 пользователях, план раскатки и что нужно от комитета.
